# Notice

`web-sidebar` is a GA Harness reimplementation of the core workbench idea of
[omdsh-dev/DSH-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar) (MIT License):
a right-hand panel with a file tree, a file viewer/editor and a Git changes view.

It was written from scratch against the GA Harness plugin API; no upstream source files are included.
Upstream features outside that core (terminal, agents, extensions, remote hosts, ...) are not part of this plugin.
